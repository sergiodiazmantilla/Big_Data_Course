# 📊 Big Data Course

Repositorio de prácticas, ejercicios y proyectos realizados en el curso de Big Data, enfocado en el análisis, procesamiento y manejo de grandes volúmenes de datos.

# 📌 Descripción

Este repositorio contiene actividades relacionadas con el procesamiento de datos a gran escala, análisis de información y fundamentos de Big Data, aplicando herramientas y conceptos modernos del área.

# 🎯 Objetivos del curso
- Comprender los fundamentos de Big Data
- Aprender el manejo de grandes volúmenes de datos
- Aplicar técnicas de procesamiento y análisis
- Entender el flujo de datos (ingesta, procesamiento y salida)
- Introducción a herramientas del ecosistema Big Data

# 🧠 Contenidos
1. Introducción a Big Data
2. Características (5V: volumen, velocidad, variedad, veracidad, valor)
3. Procesamiento de datos
4. Modelos de almacenamiento
5. Análisis de datos
6. Casos prácticos

# 🛠️ Herramientas y tecnologías
- Python 🐍
- SQL / Bases de datos
- Conceptos de Hadoop / Spark (si aplica en tu curso)
- Excel para análisis básico
- Visualización de datos
